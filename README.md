# Mayank3613 Homebrew Tap

Official Homebrew tap for [RAMLLM](https://github.com/Mayank3613/RAMLLM) — Run bigger models on smaller machines with RAM-adaptive, GPU-aware LLM inference.

## Installation

```bash
brew install Mayank3613/tap/ramllm
```

## Update

```bash
brew update
brew upgrade ramllm
```
